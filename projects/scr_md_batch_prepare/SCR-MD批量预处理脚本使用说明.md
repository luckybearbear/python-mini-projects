# SCR\-MD批量预处理脚本使用说明

## 一、脚本介绍

**脚本名称**：scr\_md\_batch\_prepare\.py

**核心用途**：专为 **Obsidian Supercharged Repetition（SCR）闪卡插件** 批量格式化 Markdown 笔记，一键将普通面试/学习文档转为标准 SCR 可识别闪卡格式，适配插件解析规则，零手动修改。

**适用场景**：Java/编程笔记、面试题库、知识点文档批量转闪卡

## 二、核心功能

1. **清除头部元数据**：自动删除文档开头 `---` 包裹的 YAML 配置头，避免插件解析异常、乱码。

2. **自动生成问答分隔符**：所有三级标题`### 知识点标题` 下方自动插入单独一行 `?`，匹配 SCR 问答卡识别规则（上问下答）。

3. **标准化卡片分隔线**：每个知识点卡片末尾添加 `---`，**上下自带空行**，严格适配 SCR 分隔规范，杜绝卡片粘连、解析合并问题。

4. **全局批量处理**：递归遍历目标文件夹，一键处理所有 `.md` 文件，支持多级子目录。

5. **安全不覆盖原文件**：处理后文件自动生成 `xxx_out.md` 新文件，原始笔记完整保留，无丢失风险。

6. **自动规整格式**：清理多余空行、乱换行，统一全文排版样式。

- 将所有需要转换的 Markdown 笔记放入该文件夹

- 将脚本 `scr_md_batch_prepare.py` 放在同级目录

### 2\. 脚本配置

打开脚本，修改下方路径为你的笔记文件夹路径：

## 七、注意事项

1. **不破坏原文件**：所有修改均生成新文件，原始笔记永久保留，可放心批量处理

2. **严格适配 SCR 规则**：分隔线上下空行格式为插件最优解析格式，不会出现卡片合并、不识别问题

3. **支持多级目录**：自动遍历子文件夹内所有 MD 文件，无需手动拆分

4. **兼容注释内容**：保留原文所有注释、拓展内容、链接、引用，仅优化格式

5. **禁止手动删减空行**：分隔线上下空行为插件必需格式，删除会导致闪卡解析异常

## 八、常见问题

#### Q1：运行后没有生成文件？

检查 `TARGET_FOLDER` 路径是否正确，文件夹内是否存在 `.md` 文件。

#### Q2：SCR 识别不到卡片？

确认文件是处理后的 `_out.md` 文件，且 `?` 和 `---`格式完整、空行正常。

#### Q3：能否覆盖原文件？

默认安全模式不覆盖，如需覆盖可联系我修改脚本版本。
